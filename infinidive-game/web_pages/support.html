Quick troubleshooting

The game does not fit my screen

Use portrait orientation. Reopen the game after rotating. Browser zoom should remain at its default value. Include your device model and a screenshot if controls still overlap a notch or system area.

There is no sound

Interact with the page once, then check Master, Music, and Sound Effects in Settings. Mobile browsers can block audio until the first user interaction. Also check the device's silent mode and connected audio output.

Touch movement or dash feels wrong

Adjust Control Sensitivity and try Dedicated Button, Double Tap, or Quick Flick in Settings. Include the selected method and handedness in the report.

A Friend Rift code will not open

Copy and paste the complete code beginning with ID1., with no surrounding message text. Invalid or altered codes are intentionally rejected. Friend Rifts are local codes; the current build has no remote invitation service.

My progress appears damaged

Close and reopen the game once. The save system can recover from one local backup. Do not clear app or site data before contacting support if you want us to help diagnose the problem.

I want to delete local progress

Settings includes Reset Progress with a confirmation. It replaces currencies, unlocks, settings, tutorial and other profile progress—and its recovery backup—with clean defaults, and deletes the local diagnostics queue plus the Daily/Friend result primary, backup, and temporary files. Uninstalling or clearing the native app's storage, or clearing stored site data for the exact Web origin, remains the broadest way to remove platform-managed or future local files. Reset and platform/site-storage deletion are permanent; the current build has no cloud copy to restore.

Current pre-release limitations

  • No account, cloud save, online leaderboard, or remote friend service is connected.
  • No advertising, in-app purchase, subscription, or restore-purchase flow exists.
  • Android declares only the normal vibration permission for optional haptics; it has no runtime prompt and does not collect data.
  • The public browser pre-release is available at matanita44-sudo.github.io/claude-builders-bounty/infinidive/. No production-signed Android/iOS test build, mobile-browser compatibility result, or physical-device QA result is claimed here.
  • Hebrew runtime UI and right-to-left text layout are implemented; physical-device text-fit testing is still pending.

פתרון תקלות מהיר

המשחק אינו מתאים למסך

השתמשו בכיוון אנכי. פתחו מחדש את המשחק לאחר סיבוב. יש להשאיר את זום הדפדפן בערך ברירת המחדל. אם פקדים עדיין חופפים למגרעת או לאזור מערכת, צרפו את דגם המכשיר וצילום מסך.

אין שמע

בצעו פעולה אחת בעמוד ולאחר מכן בדקו בהגדרות את עוצמת השמע הראשית, המוזיקה והאפקטים. דפדפנים בנייד עשויים לחסום שמע עד לאינטראקציה הראשונה. בדקו גם מצב שקט ואת התקן השמע המחובר.

התנועה או הדאש אינם מרגישים נכון

כוונו את רגישות השליטה ונסו כפתור ייעודי, הקשה כפולה או החלקה מהירה בהגדרות. בדיווח ציינו את השיטה ואת העדפת היד שנבחרו.

קוד Friend Rift אינו נפתח

העתיקו והדביקו את הקוד המלא שמתחיל ב־ID1., ללא טקסט נוסף מסביב. קוד לא תקין או ששונה נדחה בכוונה. אתגרי Friend Rift הם קודים מקומיים; בגרסה הנוכחית אין שירות הזמנות מרוחק.

נראה שההתקדמות נפגמה

סגרו ופתחו את המשחק פעם אחת. מערכת השמירה יכולה להתאושש מגיבוי מקומי אחד. אל תמחקו את נתוני האפליקציה או האתר לפני פנייה לתמיכה אם ברצונכם שננסה לאבחן את הבעיה.

ברצוני למחוק את ההתקדמות המקומית

בהגדרות קיימת פעולת איפוס התקדמות עם אישור. היא מחליפה מטבעות, פתיחות, הגדרות, הדרכה, התקדמות פרופיל וגיבוי שחזור בברירות מחדל נקיות, ומוחקת את תור הניתוח המקומי ואת קובצי תוצאות Daily/Friend הראשי, הגיבוי והקובץ הזמני. הסרת האפליקציה או מחיקת האחסון שלה, ובדפדפן מחיקת נתוני האתר עבור כתובת המקור המדויקת, נשארות הדרך הרחבה ביותר למחיקת קבצים שמנוהלים בידי הפלטפורמה או שיתווספו בעתיד. האיפוס ומחיקת אחסון המערכת/האתר הם קבועים; בגרסה הנוכחית אין עותק ענן לשחזור.

מגבלות גרסת טרום־ההשקה

  • אין חשבון, שמירת ענן, לוח תוצאות מקוון או שירות חברים מרוחק.
  • אין פרסומות, רכישות בתוך האפליקציה, מנויים או שחזור רכישות.
  • ב־Android מוצהרת רק הרשאת הרטט הרגילה עבור משוב אופציונלי; היא אינה מציגה בקשת הרשאה בזמן ריצה ואינה אוספת מידע.
  • גרסת טרום־ההשקה הציבורית לדפדפן זמינה בכתובת matanita44-sudo.github.io/claude-builders-bounty/infinidive/. עמוד זה אינו טוען שקיים מבנה Android/iOS חתום לייצור, אימות תאימות בדפדפן נייד או תוצאת בדיקה במכשיר פיזי.
  • ממשק המשחק תורגם לעברית וכולל פריסת טקסט מימין לשמאל; בדיקת התאמת הטקסט במכשירים פיזיים עדיין ממתינה.
