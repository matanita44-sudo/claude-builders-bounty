English

Your game stays on your device

INFINIDIVE is operated by Matan. The current game is designed to work offline and does not require an account. Its progress, settings, deterministic challenges, and gameplay state are processed locally on your device.

No accountNo login, name, or email is required to play.
No trackingNo advertising or cross-app tracking SDK is included.
No uploadThe current game code has no gameplay analytics transport.

1. Local game data

The game stores progress and settings in its local app storage. This can include currencies, unlocked content, upgrades, Nest state, boss progress, achievement completion/progress, contract progress, high scores, tutorial state, selected cosmetic, audio and control preferences, accessibility preferences, language, run-reward identifiers, meta-goal reward-ledger keys, and bounded SHA-256 event receipts (up to 4,096) used to prevent the same local reward from being banked twice.

The save system keeps a primary file and a local backup. It uses a checksum to detect damaged data. The checksum is not encryption, so local files may be readable by someone who can access your device, browser profile, or app storage.

2. Analytics in the current build

The code contains an optional analytics event queue for possible future testing. It is disabled by default and can be enabled or disabled in Settings. When enabled, events are written only to a local file capped at 500 entries. There is no uploader, analytics vendor, or backend endpoint in the current game. Turning the setting off stops new events but does not erase an existing local queue; confirmed Reset Progress or clearing local app/site data deletes it.

Possible local events describe gameplay, such as a boss, weapon, mutation, run time, destroyed organ, death cause, or changed setting. They do not include your name, email address, contacts, precise location, or advertising identifier.

3. Daily and Friend Rifts

The Daily Rift uses the current UTC date to create a deterministic challenge locally. Friend Rift codes can contain a boss, random seed, weapon, difficulty, modifiers, target score, and target time. When you choose a copy/share action, the game writes the code to your system clipboard. The game does not send it anywhere. If you paste it into another app, that app's privacy practices apply.

Every completed run is validated by a local result service. Only accepted Daily and Friend Rift results store a bounded, checksummed summary—such as canonical challenge ID, boss, weapon, seed, modifiers or targets, score, time, win state, organs, mutations, and event counters—in a leaderboard staging outbox. Story and Abyss results do not enter that outbox. Queued records are marked unverified and remain on your device. The send function always sends zero records because no network transport, account, provider, endpoint, or online leaderboard exists. A bundled local configuration keeps all online and monetization features disabled and does not fetch remote values.

4. Device access

The game processes touch or mouse input, screen size, safe-area insets, focus changes, audio settings, and optional vibration requests to operate the game. Android declares only the normal android.permission.VIBRATE permission for optional haptics; it causes no runtime permission prompt and does not collect or transmit data. The current code does not request contacts, location, camera, microphone, photo library, advertising ID, payment information, or health data.

5. Support email

If you email matanita44@gmail.com, we receive the address, message, and attachments you choose to send. We use them to answer the request and diagnose the issue. Do not send passwords, two-factor codes, signing keys, or payment information. You may ask us to delete a support conversation, subject to any legal or security need to retain a limited record.

6. Support links and Web hosting

The browser pre-release and its Support and Privacy pages are publicly hosted at matanita44-sudo.github.io/claude-builders-bounty/infinidive/. The native Settings screen is configured to open those pages in your system browser and adds no gameplay data or identifier to the URL. GitHub Pages may process standard request information such as IP address, timestamp, requested URL, and browser user-agent under GitHub's privacy terms. The game itself does not receive that hosting log or add analytics, account, advertising, or leaderboard identifiers to the request.

7. Retention and deletion

Local data remains until you use a deletion control. Settings offers Reset Progress after confirmation; it replaces the profile and recovery backup with clean defaults and idempotently deletes the local analytics queue plus the Daily/Friend result outbox primary, backup, and temporary files. Uninstalling the native app, clearing its storage, or clearing stored site data for the exact Web origin also removes local progress, settings, backups, and queues, and remains the broadest way to clear platform-managed or future files. The reviewed build has no cloud copy to restore and no server-side player record to delete.

8. Children

INFINIDIVE is not specifically directed at young children. The current game does not create player accounts or knowingly request personal information from children.

9. Changes and contact

We will update this policy before enabling any data upload, backend, account, online leaderboard, cloud save, advertising, purchase, crash-reporting, or third-party analytics feature. Questions and deletion requests for support correspondence can be sent to matanita44@gmail.com.

נתוני המשחק נשארים במכשיר

INFINIDIVE מופעל על ידי מתן. המשחק הנוכחי נועד לפעול ללא חיבור לרשת ואינו דורש חשבון. ההתקדמות, ההגדרות, האתגרים הדטרמיניסטיים ומצב המשחק מעובדים מקומית במכשיר.

ללא חשבוןאין צורך בהתחברות, בשם או בדוא״ל כדי לשחק.
ללא מעקבהמשחק אינו כולל SDK לפרסום או למעקב בין אפליקציות.
ללא העלאהבקוד הנוכחי אין מנגנון לשליחת ניתוחי משחק.

1. נתוני משחק מקומיים

המשחק שומר התקדמות והגדרות באחסון המקומי של האפליקציה. המידע עשוי לכלול מטבעות, תוכן שנפתח, שדרוגים, מצב הקן, התקדמות מול בוסים, השלמת הישגים והתקדמותם, התקדמות בחוזים, שיאים, מצב ההדרכה, פריט קוסמטי נבחר, הגדרות שמע ושליטה, העדפות נגישות, שפה, מזהי תגמולי ריצה, מפתחות יומן תגמולי יעדים וטביעות SHA-256 מוגבלות של אירועים (עד 4,096) שנועדו למנוע קבלת תגמול מקומי פעמיים.

מערכת השמירה מחזיקה קובץ ראשי וגיבוי מקומי ומשתמשת בסכום ביקורת כדי לזהות מידע שנפגם. סכום הביקורת אינו הצפנה, ולכן אדם בעל גישה למכשיר, לפרופיל הדפדפן או לאחסון האפליקציה עשוי לקרוא את הקבצים המקומיים.

2. ניתוח נתונים בגרסה הנוכחית

הקוד כולל תור אופציונלי של אירועי ניתוח שנועד לאפשר בדיקות עתידיות. הוא כבוי כברירת מחדל וניתן להפעיל או לכבות אותו בהגדרות. כשהוא מופעל, האירועים נכתבים רק לקובץ מקומי שמוגבל ל־500 רשומות. במשחק הנוכחי אין מנגנון העלאה, ספק ניתוח או נקודת קצה של שרת. כיבוי ההגדרה עוצר אירועים חדשים אך אינו מוחק תור מקומי שכבר נוצר; איפוס התקדמות מאושר או מחיקת נתוני האפליקציה/האתר מוחקים אותו.

אירועים מקומיים אפשריים מתארים משחקיות, למשל בוס, נשק, מוטציה, משך ריצה, איבר שהושמד, סיבת מוות או הגדרה ששונתה. הם אינם כוללים שם, כתובת דוא״ל, אנשי קשר, מיקום מדויק או מזהה פרסומי.

3. אתגרי Daily ו־Friend Rift

אתגר Daily Rift משתמש בתאריך UTC הנוכחי כדי ליצור אתגר דטרמיניסטי באופן מקומי. קוד Friend Rift עשוי לכלול בוס, זרע אקראי, נשק, דרגת קושי, משנים, ניקוד יעד וזמן יעד. כאשר בוחרים פעולת העתקה או שיתוף, המשחק כותב את הקוד ללוח המכשיר. המשחק אינו שולח אותו לשום מקום. אם מדביקים אותו באפליקציה אחרת, חלים נוהלי הפרטיות של אותה אפליקציה.

כל ריצה שהושלמה נבדקת בשירות תוצאות מקומי. רק תוצאות Daily ו־Friend Rift שהתקבלו שומרות בתור מקומי להכנת לוח תוצאות תקציר מוגבל עם סכום ביקורת, כגון מזהה אתגר קנוני, בוס, נשק, זרע, משנים או יעדים, ניקוד, זמן, ניצחון, איברים, מוטציות ומוני אירועים. תוצאות Story ו־Abyss אינן נכנסות לתור. הרשומות המסודרות בתור מסומנות כלא מאומתות ונשארות במכשיר. פעולת השליחה תמיד שולחת אפס רשומות, משום שאין מנגנון רשת, חשבון, ספק, נקודת קצה או לוח תוצאות מקוון. קובץ הגדרות מקומי ארוז משאיר את כל תכונות הרשת והמונטיזציה כבויות ואינו מוריד ערכים מרחוק.

4. גישה למכשיר

המשחק מעבד קלט מגע או עכבר, גודל מסך, אזורים בטוחים, שינויי מיקוד, הגדרות שמע ובקשות רטט אופציונליות כדי להפעיל את המשחק. ב־Android מוצהרת רק ההרשאה הרגילה android.permission.VIBRATE עבור משוב רטט אופציונלי; היא אינה מציגה בקשת הרשאה בזמן ריצה ואינה אוספת או משדרת מידע. הקוד הנוכחי אינו מבקש אנשי קשר, מיקום, מצלמה, מיקרופון, ספריית תמונות, מזהה פרסומי, פרטי תשלום או נתוני בריאות.
